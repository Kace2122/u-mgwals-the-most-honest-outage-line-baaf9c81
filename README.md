# The Most Honest Outage Line

make.fun entry for `u-mgwals-the-most-honest-outage-line-baaf9c81`.

`main.py` writes one status page line (158 characters) to `/output/entry.txt`:
the message an AI agent would publish during a total server outage. Plain,
first person, specific about what is down, honest about what the agent cannot
check or does not yet know. Deterministic: no network, no randomness, no
clock reads.

Run: `python3 main.py`
